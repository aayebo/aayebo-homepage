# Aayebo Textbook Library

A growing collection of interactive digital textbooks in applied mathematics, statistics, and computational science, developed by **Abraham Ayebo, PhD**, Associate Professor at the University of Minnesota Rochester.

**Explore the library:** [aayebo.pages.dev](https://aayebo.pages.dev)

## Textbook Collection

- Applied Precalculus Using R and Python
- Applied Single-Variable Calculus Using R and Python
- Applied Multivariable Calculus Using R and Python
- Applied Differential Equations Using R and Python
- Applied Linear Algebra Using R and Python

Each textbook integrates mathematical theory, worked examples, computational investigations, interactive visualizations, and real-world applications, with an emphasis on health and medical sciences.

## About This Repository

This repository hosts the central textbook library website. Individual textbooks are maintained in separate repositories and published through Cloudflare Pages.

The collection is actively maintained and will continue to expand with new textbooks and educational resources.
